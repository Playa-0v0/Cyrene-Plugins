# 本地语音识别契约示例（local-asr-contract）

演示本地 ASR 插件与宿主的语音输入租约契约：如何接管语音输入、提交识别文本、释放输入权。**使用模拟识别文本，不含真实模型与推理运行时**——它是给插件开发者看的参考实现，日常使用价值有限。

## 使用方式

启用插件后，对昔涟说「开始语音识别」「停止识别」体验租约流程：

1. 获取独占租约（此时宿主自身语音输入被冻结）
2. 800ms 后返回模拟识别文本并提交进当前对话
3. 提交完成自动释放租约，输入权归还宿主

## 给插件开发者的说明

真实 ASR 插件应在本示例基础上替换 `fakeRecognize` 为模型推理，并遵守契约要点：

- 识别结束或租约 signal 中止时都必须释放租约
- `commit()` 失败按稳定错误码分支处理（如会话已删除则放弃重试）
- 同一时刻只持有一个租约
