# 定时自动化（scheduled-automation）

通过对话创建和管理定时任务：让昔涟在指定时间做指定的事（提醒、日报、轮询检查等）。

## 使用方式

启用插件后，直接对昔涟说：

- 「每天早上 8 点提醒我喝水」——创建定时任务
- 「列一下我的定时任务」——查看已有任务
- 「把喝水提醒改成 9 点」——更新任务
- 「删掉喝水提醒」——删除任务

任务创建后默认停用，需要在 Cyrene 的任务界面确认启用才会真正生效。

## 行为说明

- 任务由宿主调度器统一执行，插件只负责任务的定义与管理
- 只能管理本插件自己创建的任务，不影响其他插件或宿主的任务
- 源码：[Cyrene-Agent 示例](https://github.com/Playa-0v0/Cyrene-Agent/tree/master/examples/scheduled-automation)
