# 系统状态（system-status）

查询本机系统状态：CPU、内存、GPU、磁盘、电池与开机时长，并附带一个可视化状态面板窗口。

## 使用方式

启用插件后，直接对昔涟说「电脑现在占用多少」「还剩多少电」「开了多久了」即可触发工具；也可以说「查一下 D 盘占用」查询指定磁盘。

在插件列表中打开面板，可查看 CPU / GPU / 内存 / 磁盘 / 网络 / 电池的实时图形化状态。

## 提供的工具

- `system-status_status`：系统状态总览（系统、CPU、内存、GPU、电池、开机时长）
- `system-status_disk`：磁盘占用查询，可选指定盘符（C / D / E…），不指定则查系统盘

## 行为说明

- 不访问网络
- 通过 PowerShell / WMI 只读查询系统信息（CPU 采样、磁盘、网络流量、电池、GPU 计数器）
- 装有 NVIDIA 显卡时调用 `nvidia-smi` 读取 GPU 温度与显存；未检测到时自动跳过
- GPU 数据在无 N 卡时回退 WMI 性能计数器，均不可用时显示为空
